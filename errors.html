Обработка ошибок

Rust делит ошибки на две группы: неисправимые (panic! — аварийная остановка) и исправимые (Result<T, E> — значение, которое можно вернуть и обработать).

panic! — неисправимые ошибки

Паника печатает сообщение, раскручивает стек и завершает поток. Используется для состояний «так не должно быть никогда»:

fn main() {
        let v = vec![1, 2, 3];
        println!("{}", v[99]); // panic: index out of bounds
    
        // panic!("остановись и расскажи, что произошло");
    }
# Полезный бэктрейс места паники
    $ RUST_BACKTRACE=1 cargo run

Result<T, E> — исправимые ошибки

use std::fs::File;
    use std::io::ErrorKind;
    
    fn main() {
        let f = File::open("hello.txt");
    
        let file = match f {
            Ok(file) => file,
            Err(error) => match error.kind() {
                ErrorKind::NotFound => match File::create("hello.txt") {
                    Ok(fc) => fc,
                    Err(e) => panic!("не удалось создать файл: {:?}", e),
                },
                other => panic!("не удалось открыть файл: {:?}", other),
            },
        };
        drop(file);
    }

Короче — через замыкания и комбинаторы:

use std::fs::File;
    use std::io::ErrorKind;
    
    fn main() {
        let f = File::open("hello.txt").unwrap_or_else(|error| {
            if error.kind() == ErrorKind::NotFound {
                File::create("hello.txt").expect("не удалось создать файл")
            } else {
                panic!("не удалось открыть файл: {:?}", error);
            }
        });
        drop(f);
    }
МетодПоведение при Err
.unwrap()Паника с стандартным сообщением
.expect("msg")Паника с вашим сообщением
.unwrap_or(x)Вернёт запасное значение x
.unwrap_or_else(f)Вычислит запасное значение в замыкании

Оператор ? — распространение ошибок

? после выражения с Result: при Ok достаёт значение, при Err — ранний возврат ошибки вызывающему коду:

use std::fs;
    use std::io;
    
    fn read_username() -> io::Result<String> {
        // Эквивалент длинного match: одна строка вместо десяти
        let content = fs::read_to_string("username.txt")?;
        Ok(content.trim().to_string())
    }
    
    fn main() {
        match read_username() {
            Ok(name) => println!("Привет, {}!", name),
            Err(e) => eprintln!("Ошибка: {}", e),
        }
    }

Когда что использовать

  • panic! — нарушение инвариантов, невозможное состояние, тесты, unreachable!.
  • Result — ожидаемые сбои: файлы, сеть, парсинг, ввод пользователя.
  • ? — в функциях, которые сами возвращают Result (или Option, или main с типом ошибки).

Ключевые моменты

  • Ошибки — обычные значения: enum Result<T, E> { Ok(T), Err(E) }.
  • ? заменяет «пирамиды» из match при пробросе ошибок вверх.
  • Прототипы: unwrap/expect; продакшен: Result + осмысленные сообщения.
