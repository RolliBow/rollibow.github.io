Модули, пути и cargo

Иерархия организации кода в Rust:

ПонятиеОпределение
Пакет (package)Проект cargo: один Cargo.toml, до одного бинарного и сколько угодно библиотечных крейтов
Крейт (crate)Дерево кода, которое компилируется за раз: бинарник (main.rs) или библиотека (lib.rs)
Модуль (mod)Группировка элементов внутри крейта + управление видимостью

Объявление модулей

// src/lib.rs
    mod front_of_house {
        pub mod hosting {
            pub fn add_to_waitlist() {}
    
            fn seat_at_table() {} // приватная функция
        }
    }
    
    pub fn eat_at_restaurant() {
        // Абсолютный путь — от корня крейта
        crate::front_of_house::hosting::add_to_waitlist();
    
        // Относительный путь — от текущего модуля
        front_of_house::hosting::add_to_waitlist();
    }

Без pub элементы модуля приватны — вложенность hosting снаружи недоступна. Правило: pub открывает элемент, но все его родительские модули тоже должны быть доступны.

use — импорт путей

use std::collections::HashMap;        // импортировать тип
    use std::fmt::Display as Disp;        // псевдоним
    pub use crate::front_of_house::hosting; // публичный ре-экспорт
    
    fn main() {
        let mut map = HashMap::new();
        map.insert("ключ", 42);
        hosting::add_to_waitlist();
        println!("{:?}", map);
    }

Идиома: функции импортируют вместе с родительским модулем (use std::io; → io::Result), а типы — напрямую.

Модули в отдельных файлах

src/
    ├── lib.rs                 # mod front_of_house; + корень дерева
    └── front_of_house/
        ├── mod.rs (или front_of_house.rs)
        └── hosting.rs         # mod hosting; внутри front_of_house
// src/lib.rs — тело модуля вынесено в файл
    pub mod front_of_house;
    
    pub use crate::front_of_house::hosting;
    
    pub fn eat_at_restaurant() {
        hosting::add_to_waitlist();
    }

Зависимости в Cargo.toml

[package]
    name = "my_app"
    version = "0.1.0"
    edition = "2021"
    
    [dependencies]
    rand = "0.8"        # с crates.io
    serde = { version = "1.0", features = ["derive"] }
use rand::Rng;
    
    fn main() {
        let n: u8 = rand::thread_rng().gen_range(1..=6);
        println!("Кубик выпал: {}", n);
    }

Ключевые моменты

  • Пакет ⊃ крейты ⊃ модули; видимость управляется pub.
  • Пути бывают абсолютные (crate::) и относительные.
  • Один модуль = один файл (или каталог) — конвенция раскладки кода.
