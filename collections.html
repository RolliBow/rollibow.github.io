Коллекции: Vec, String, HashMap

В отличие от массива и кортежа, коллекции хранятся в куче, а их размер может меняться во время выполнения.

Vec<T> — динамический массив

fn main() {
        let mut v: Vec<i32> = Vec::new();
        v.push(5);
        v.push(6);
        v.push(7);
    
        let v2 = vec![1, 2, 3];       // макрос с начальными значениями
    
        let third = &v2[2];           // индексация: паника при выходе за границы
        let safe = v2.get(2);         // Option<&i32>: None вместо паники
    
        println!("{} {:?}", third, safe);
    
        for item in &v2 {             // итерация по ссылке
            print!("{} ", item);
        }
        println!();
    
        for item in &mut v {          // мутабельная итерация
            *item *= 10;
        }
        println!("{:?}", v);          // [50, 60, 70]
    }

String — растущая строка

String — изменяемая строка в куче; &str — неизменяемый срез (литералы — именно &str). Строки — это UTF-8, поэтому индексация по символу s[0] запрещена:

fn main() {
        let mut s = String::from("При");
        s.push_str("вет");            // добавить срез
        s.push('!');                  // добавить char
    
        let s1 = String::from("1, ");
        let s2 = String::from("2, 3");
        let s3 = s1 + &s2;            // + забирает владение s1
        let joined = format!("{} + {}", s3, "итог"); // format! не забирает владение
    
        println!("{}", joined);
    
        for c in "Здр🦀".chars() {    // итерация по символам
            print!("[{}] ", c);
        }
        println!();
    }

HashMap<K, V> — хеш-таблица

use std::collections::HashMap;
    
    fn main() {
        let mut scores: HashMap<String, i32> = HashMap::new();
        scores.insert(String::from("Blue"), 10);
        scores.insert(String::from("Yellow"), 50);
    
        let team = String::from("Blue");
        let score = scores.get(&team).copied().unwrap_or(0); // get -> Option<&V>
        println!("{}", score);
    
        // entry: вставить, только если ключа ещё нет
        scores.entry(String::from("Red")).or_insert(0);
    
        for (key, value) in &scores {
            println!("{key}: {value}");
        }
    }

Классическая задача — подсчёт слов:

use std::collections::HashMap;
    
    fn word_count(text: &str) -> HashMap<String, u32> {
        let mut map = HashMap::new();
        for word in text.split_whitespace() {
            let count = map.entry(word.to_string()).or_insert(0);
            *count += 1;
        }
        map
    }
    
    fn main() {
        let text = "the quick brown fox jumps over the lazy dog the end";
        println!("{:?}", word_count(text));
    }

Коллекции и владение

  • Коллекция владеет своими элементами: при удалении вектора удаляются и значения.
  • insert перемещает ключ и значение в таблицу (для String).
  • Итерация по &v заимствует элементы, по v — забирает владение.

Ключевые моменты

  • vec![], String::from, HashMap::new — стандартные способы создания.
  • Безопасный доступ к элементам — get(), возвращающий Option.
  • entry(...).or_insert(...) — идиоматичная работа с HashMap.
