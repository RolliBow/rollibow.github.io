Дженерики и трейты

Дженерики убирают дублирование: один алгоритм работает с разными типами. Трейты описывают поведение, которое типы могут реализовывать (аналог интерфейсов).

Обобщённые функции

fn largest<T: PartialOrd>(list: &[T]) -> &T {
        let mut largest = &list[0];
        for item in &list[1..] {
            if item > largest {
                largest = item;
            }
        }
        largest
    }
    
    fn main() {
        let numbers = vec![34, 50, 25, 100, 65];
        println!("Максимум: {}", largest(&numbers)); // 100
    
        let letters = vec!['y', 'm', 'a', 'q'];
        println!("Максимум: {}", largest(&letters)); // 'y'
    }

Запись T: PartialOrd — ограничение трейта: функция принимает только те T, которые умеют сравниваться.

Обобщённые структуры

#[derive(Debug)]
    struct Point<T> {
        x: T,
        y: T,
    }
    
    impl<T> Point<T> {
        fn x(&self) -> &T {
            &self.x
        }
    }
    
    fn main() {
        let integer = Point { x: 5, y: 10 };
        let float = Point { x: 1.0, y: 4.0 };
        println!("{:?} — {}", integer, integer.x());
    }

Трейты

Трейт объявляет сигнатуры методов; часть методов может иметь реализацию по умолчанию:

pub trait Summary {
        fn summarize(&self) -> String;          // обязателен
    
        fn preview(&self) -> String {           // реализация по умолчанию
            format!("Читать далее: {}...", self.summarize())
        }
    }
    
    pub struct Article {
        pub headline: String,
        pub author: String,
    }
    
    impl Summary for Article {
        fn summarize(&self) -> String {
            format!("{}, автор {}", self.headline, self.author)
        }
    }
    
    fn main() {
        let a = Article {
            headline: String::from("Rust 1.90"),
            author: String::from("Red"),
        };
        println!("{}", a.preview()); // использует метод по умолчанию
    }

Трейты как параметры

// Синтаксический сахар impl Trait
    fn notify(item: &impl Summary) {
        println!("Срочные новости! {}", item.summarize());
    }
    
    // То же через дженерик с ограничением
    fn notify2<T: Summary>(item: &T) {
        println!("Срочные новости! {}", item.summarize());
    }
    
    // Несколько трейтов: + ; полная форма — where
    fn print_it<T>(item: &T)
    where
        T: Summary + std::fmt::Display,
    {
        println!("{}", item.summarize());
    }

Частые трейты стандартной библиотеки

ТрейтЧто даёт
DebugОтладочная печать {:?}
CloneЯвное глубокое копирование .clone()
CopyНеявное копирование присваиванием (маркерный трейт)
PartialEq / EqСравнение ==
PartialOrd / OrdСортировка, <, >
DefaultЗначение по умолчанию Default::default()
IteratorЛенивые цепочки .map().filter().collect()

Ключевые моменты

  • Дженерики — мономорфизация: компилятор генерирует код под каждый конкретный тип, нулевая цена в рантайме.
  • Трейт = контракт поведения; impl Trait for Type — реализация.
  • Ограничения (T: Trait) говорят компилятору, что умеет обобщённый тип.
