Перечисления и сопоставление с образцом

Перечисление (enum) — тип, значение которого может быть одним из нескольких вариантов. Варианты могут нести данные, как структуры.

Определение enum

enum Message {
        Quit,                       // без данных
        Move { x: i32, y: i32 },    // анонимная структура
        Write(String),              // одно поле
        ChangeColor(u8, u8, u8),    // кортеж
    }
    
    impl Message {
        fn call(&self) {
            println!("обработка сообщения");
        }
    }
    
    fn main() {
        let m = Message::Write(String::from("привет"));
        m.call(); // методы доступны и у enum
    }

Option — замена null

В Rust нет null. «Отсутствие значения» выражается перечислением Option<T> из стандартной библиотеки — и компилятор заставляет обработать оба случая:

let some_number: Option<i32> = Some(5);
    let absent_number: Option<i32> = None;
    
    fn main() {
        let x: i32 = 5;
        let y: Option<i32> = Some(3);
    
        // let sum = x + y; // ОШИБКА: i32 и Option<i32> — разные типы
        let sum = x + y.unwrap_or(0); // сначала «распаковать» значение
        println!("sum = {}", sum);
    }

match — сопоставление с образцом

match перебирает шаблоны и обязан покрыть все варианты. Внутри варианта данные можно связать с переменными:

#[derive(Debug)]
    enum Coin {
        Penny,
        Nickel,
        Dime,
        Quarter(String), // редкая монета с именем штата
    }
    
    fn value_in_cents(coin: Coin) -> u32 {
        match coin {
            Coin::Penny => {
                println!("Счастливая монетка!");
                1
            }
            Coin::Nickel => 5,
            Coin::Dime => 10,
            Coin::Quarter(state) => {
                println!("Штат: {}", state);
                25
            }
        }
    }
    
    fn main() {
        println!("{}", value_in_cents(Coin::Quarter(String::from("Alaska"))));
    }

Match с Option:

fn plus_one(x: Option<i32>) -> Option<i32> {
        match x {
            Some(i) => Some(i + 1),
            None => None, // пропустить ветку нельзя — не скомпилируется
        }
    }

Шаблон _ — «всё остальное» (аналог default в switch):

let dice = 9;
    match dice {
        3 => println!("добавить шляпу"),
        7 => println!("убрать шляпу"),
        _ => println!("ничего не делать"),
    }

if let — короткая запись

Когда интересен только один шаблон, вместо match удобнее if let:

let config_max: Option<u8> = Some(3);
    
    if let Some(max) = config_max {
        println!("Максимум: {}", max);
    }

Ключевые моменты

  • Варианты enum могут нести данные разных форм.
  • Option<T> делает «null-ошибки» невозможными: пустое значение придётся обработать явно.
  • match исчерпывающий; if let — синтаксический сахар для одного случая.
