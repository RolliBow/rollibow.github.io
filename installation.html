Установка и первая программа

Тулчейн Rust устанавливается через rustup — официальный менеджер версий. Он ставит компилятор rustc, пакетный менеджер cargo и документацию.

Установка rustup

# Linux / macOS
    $ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
    
    # Windows — скачать и запустить rustup-init.exe с сайта rustup.rs
    
    # После установки проверить версии
    $ rustc --version
    $ cargo --version

Полезные команды rustup: rustup update — обновить тулчейн, rustup doc — открыть локальную документацию.

Первый проект на cargo

Cargo создаёт проект, скачивает зависимости, компилирует и запускает код:

$ cargo new hello_rust     # создать бинарный проект
    $ cd hello_rust
    $ cargo build              # скомпилировать
    $ cargo run                # скомпилировать и запустить

Структура проекта:

hello_rust/
    ├── Cargo.toml      # манифест: имя, версия, зависимости
    └── src/
        └── main.rs     # точка входа

Код программы

Содержимое src/main.rs по умолчанию:

fn main() {
        println!("Hello, world!");
    }
  • fn main() — точка входа: функция без аргументов и возвращаемого значения.
  • println! — макрос (отсюда !): в отличие от функции, он раскрывается на этапе компиляции и принимает переменное число аргументов.
  • Каждое выражение завершается точкой с запятой ;.

Ключевые моменты

  • rustup управляет версиями тулчейна, cargo — проектами и зависимостями.
  • cargo run = cargo build + запуск бинарника.
  • Макросы вызываются с !: println!, vec!, format!.
