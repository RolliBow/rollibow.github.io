Заимствование, ссылки и срезы

Ссылка &T позволяет пользоваться значением, не забирая владение. Это называется заимствованием (borrowing): как и в жизни, взяв книгу у друга, вы обязаны её вернуть.

Иммутабельные ссылки

fn calculate_length(s: &String) -> usize {
        s.len()
    } // s выходит из области видимости, но значение НЕ уничтожается — оно не её
    
    fn main() {
        let s1 = String::from("привет");
        let len = calculate_length(&s1);       // заимствование
        println!("Длина '{}' — {}", s1, len);  // s1 по-прежнему действительна
    }

Мутабельные ссылки

Ссылка &mut T позволяет изменять заимствованное значение:

fn change(s: &mut String) {
        s.push_str(", мир");
    }
    
    fn main() {
        let mut s = String::from("привет"); // сама переменная тоже mut
        change(&mut s);
        println!("{}", s); // привет, мир
    }

Правила заимствования

В любой момент времени существует либо одна мутабельная ссылка, либо любое число иммутабельных. Ссылки всегда должны быть действительны (никаких висячих указателей).

let mut s = String::from("привет");
    
    let r1 = &s;      // ОК
    let r2 = &s;      // ОК: сколько угодно иммутабельных
    // let r3 = &mut s; // ОШИБКА: нельзя &mut, пока существуют &
    println!("{}, {}", r1, r2);
    
    let r3 = &mut s;  // ОК: иммутабельные больше не используются (NLL)
    r3.push_str("!");
    println!("{}", r3);

Эти правила отсекают гонки данных на этапе компиляции: невозможно, чтобы один код читал значение, которое другой код параллельно изменяет.

Срезы

Срез — ссылка на непрерывную часть последовательности:

fn main() {
        let s = String::from("привет мир");
        let hello = &s[0..6];   // срез первых байт... осторожнее с UTF-8!
        let ascii = String::from("hello world");
        let word = &ascii[0..5];
        println!("{} {}", word, hello.len());
    }

Строковый срез &str — самый практичный тип параметров для строк: функция принимает и String, и строковые литералы:

fn first_word(s: &str) -> &str {
        let bytes = s.as_bytes();
        for (i, &byte) in bytes.iter().enumerate() {
            if byte == b' ' {
                return &s[..i];
            }
        }
        &s[..]
    }
    
    fn main() {
        let s = String::from("привет мир");
        println!("{}", first_word(&s));     // из String
        println!("{}", first_word("hello world")); // из литерала
    }

Времена жизни (кратко)

Когда функция возвращает ссылку, компилятору нужна подсказка, из какого аргумента она происходит — это аннотация времени жизни 'a:

fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
        if x.len() > y.len() { x } else { y }
    }

Ключевые моменты

  • Ссылки заимствуют значение: владение остаётся у владельца.
  • Одна &mut ИЛИ много & — иначе ошибка компиляции.
  • В сигнатурах функций предпочитайте &str вместо &String.
