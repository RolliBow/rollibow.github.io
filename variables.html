Переменные и изменяемость

По умолчанию переменные в Rust неизменяемы (immutable): после привязки значения к имени его нельзя заменить. Изменяемость включается явно ключевым словом mut.

let и mut

fn main() {
        let x = 5;
        println!("x = {}", x);
    
        // x = 6; // ОШИБКА: нельзя присвоить значение неизменяемой переменной
    
        let mut y = 10;
        y = 20;    // ОК: y объявлена как mut
        println!("y = {}", y);
    }

Неизменяемость по умолчанию — часть гарантий безопасности: компилятор подтверждает, что значение никогда не изменится.

Константы

Константы объявляются через const: тип обязателен, значение известно на этапе компиляции, область видимости — любая, включая глобальную.

const MAX_POINTS: u32 = 100_000;
    const SECONDS_IN_HOUR: u64 = 60 * 60; // можно вычислять константные выражения
    
    fn main() {
        println!("Лимит: {} очков", MAX_POINTS);
    }

Затенение (shadowing)

Повторный let с тем же именем затеняет предыдущую переменную: создаётся новая привязка, которая может даже иметь другой тип.

fn main() {
        let spaces = "   ";        // тип &str
        let spaces = spaces.len(); // затенение: теперь это usize
    
        let x = 5;
        let x = x + 1;
        let x = x * 2;
        println!("x = {}, spaces = {}", x, spaces); // x = 12, spaces = 3
    }

Ключевые моменты

  • Переменные неизменяемы, если не указано mut.
  • const требует явного типа и существует на этапе компиляции.
  • Затенение создаёт новую переменную — тип можно менять.
