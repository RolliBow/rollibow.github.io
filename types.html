Типы данных

Rust — статически типизированный язык: тип каждого значения известен на этапе компиляции. Обычно компилятор выводит тип сам, но его можно указать явно: let x: i32 = 42;.

let answer: i32 = -42;        // явно
    let port = 8080u16;           // суффикс типа
    let big = 1_000_000;          // разделители разрядов
    let hex = 0xff_u8;            // шестнадцатеричный
    let pi = 3.14159;             // f64 по умолчанию
    let flag: bool = true;
    let letter: char = 'z';
    let unicode: char = 'ℤ';
    let crab: char = '🦀';        // char — это Unicode-скаляр (4 байта)

Кортежи (tuples)

Кортеж хранит значения разных типов фиксированной длины:

fn main() {
        let tup: (i32, f64, bool) = (500, 6.4, true);
    
        let (x, y, z) = tup;          // деструктуризация
        let first = tup.0;            // доступ по индексу
        println!("{} {} {} {}", x, y, z, first);
    }

Массивы

Массив — значения одного типа фиксированной длины, размещается в стеке:

fn main() {
        let a = [1, 2, 3, 4, 5];
        let zeros = [0; 5];       // [0, 0, 0, 0, 0]
    
        let first = a[0];
        println!("{:?} {}", a, first);
    }

Границы проверяются. Обращение a[10] к массиву из 5 элементов вызывает панику index out of bounds во время выполнения — молчаливого чтения чужой памяти, как в C, не будет.

Когда длина заранее неизвестна, используют Vec<T> — динамический массив из стандартной библиотеки (см. раздел «Коллекции»).

Ключевые моменты

  • Целые по умолчанию — i32, вещественные — f64.
  • char занимает 4 байта и хранит любой Unicode-скаляр.
  • Кортеж — разнотипный, массив — однотипный фиксированной длины.
