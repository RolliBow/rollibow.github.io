Управляющие конструкции

if / else

Условие обязательно имеет тип bool — «истинных» значений, как в Python или JS, нет:

fn main() {
        let number = 7;
    
        if number % 3 == 0 {
            println!("делится на 3");
        } else if number % 2 == 0 {
            println!("делится на 2");
        } else {
            println!("нечётное и не делится на 3");
        }
    }

if — это выражение

Ветки if возвращают значения, поэтому его можно использовать справа от let (аналог тернарного оператора из других языков):

fn main() {
        let condition = true;
        let number = if condition { 5 } else { 6 };
        println!("number = {}", number);
    }

Типы во всех ветках должны совпадать: if c { 5 } else { "пять" } не скомпилируется.

loop — бесконечный цикл

loop повторяется, пока не встретит break. Цикл тоже может возвращать значение:

fn main() {
        let mut counter = 0;
    
        let result = loop {
            counter += 1;
            if counter == 10 {
                break counter * 2; // значение, возвращаемое циклом
            }
        };
        println!("result = {}", result); // 20
    }

while

fn main() {
        let mut n = 3;
        while n != 0 {
            println!("{}!", n);
            n -= 1;
        }
        println!("Пуск!");
    }

for и диапазоны

Самый частый цикл в Rust — for по итератору или диапазону:

fn main() {
        for i in 0..5 {          // 0, 1, 2, 3, 4 (исключая 5)
            print!("{} ", i);
        }
        println!();
    
        for i in (1..4).rev() {  // 3, 2, 1
            print!("{} ", i);
        }
        println!();
    
        let a = [10, 20, 30];
        for value in a {         // по элементам массива
            print!("{} ", value);
        }
        println!();
    }
ДиапазонЗначения
1..51, 2, 3, 4
1..=51, 2, 3, 4, 5

Ключевые моменты

  • if, loop и блоки — выражения: они возвращают значения.
  • Условие — строго bool.
  • Для итераций почти всегда подходит for с диапазоном или коллекцией.
