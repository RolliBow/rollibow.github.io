Структуры и методы

Структура — пользовательский тип, объединяющий именованные поля.

Определение и создание

struct User {
        username: String,
        email: String,
        sign_in_count: u64,
        active: bool,
    }
    
    fn main() {
        let user = User {
            email: String::from("someone@example.com"),
            username: String::from("someusername123"),
            active: true,
            sign_in_count: 1,
        };
    
        // Сокращение инициализации: имена полей совпадают с переменными
        let email = String::from("another@example.com");
        let username = String::from("another123");
        let user2 = User { email, username, active: true, sign_in_count: 1 };
    
        println!("{} <{}>", user.username, user.email);
    }

Виды структур

// Классическая — именованные поля
    struct Point { x: i32, y: i32 }
    
    // Кортежная — поля без имён
    struct Color(u8, u8, u8);
    
    // Единичная — без полей (реализует трейт, поле не нужно)
    struct Marker;
    
    fn main() {
        let p = Point { x: 1, y: 2 };
        let black = Color(0, 0, 0);
        println!("{} {}", p.x, black.0);
    }

Отладочный вывод: derive(Debug)

Структуры нельзя напечатать через {}, но атрибут #[derive(Debug)] включает формат {:?}:

#[derive(Debug)]
    struct Rect { w: u32, h: u32 }
    
    fn main() {
        let r = Rect { w: 30, h: 50 };
        println!("{:?}", r);   // Rect { w: 30, h: 50 }
        println!("{:#?}", r);  // то же, но в несколько строк
    }

Методы и ассоциированные функции

Методы определяются в блоке impl. Первый параметр метода — всегда &self (или &mut self, self). Функция без self — ассоциированная, вызывается через :: (как String::from):

#[derive(Debug)]
    struct Rectangle {
        width: u32,
        height: u32,
    }
    
    impl Rectangle {
        // ассоциированная функция — «конструктор»
        fn square(size: u32) -> Self {
            Self { width: size, height: size }
        }
    
        // метод: читает поля
        fn area(&self) -> u32 {
            self.width * self.height
        }
    
        // метод: принимает другую структуру
        fn can_hold(&self, other: &Rectangle) -> bool {
            self.width > other.width && self.height > other.height
        }
    
        // метод, изменяющий self
        fn scale(&mut self, factor: u32) {
            self.width *= factor;
            self.height *= factor;
        }
    }
    
    fn main() {
        let mut rect = Rectangle { width: 30, height: 50 };
        let sq = Rectangle::square(10);
    
        println!("Площадь: {}", rect.area());
        println!("Вмещает квадрат: {}", rect.can_hold(&sq));
    
        rect.scale(2);
        println!("{:?}", rect); // Rectangle { width: 60, height: 100 }
    }

Ключевые моменты

  • Три вида структур: с полями, кортежные и единичные.
  • #[derive(Debug)] + {:?} — стандартный способ печати.
  • Методы живут в impl; &self — метод, без self — ассоциированная функция.
