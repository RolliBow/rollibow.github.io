Функции

Функции объявляются ключевым словом fn. Соглашение об именовании — snake_case. Функции можно вызывать до объявления — порядок в файле не важен.

Параметры

Тип каждого параметра указывается обязательно — это часть сигнатуры:

fn greet(name: &str, times: u32) {
        for _ in 0..times {
            println!("Привет, {}!", name);
        }
    }
    
    fn main() {
        greet("мир", 3);
    }

Инструкции и выражения

Важное различие Rust:

  • Инструкции выполняют действие и не возвращают значение: let x = 5;
  • Выражения вычисляют значение: 5 + 6, вызов функции, блок кода.
fn main() {
        let y = {          // блок — это выражение!
            let x = 3;
            x + 1          // без точки с запятой — значение блока
        };
        println!("y = {}", y); // 4
    }

Точка с запятой превращает выражение в инструкцию. Случайно поставленная ; после возвращаемого значения — классическая ошибка новичка.

Возвращаемые значения

Тип возврата указывается после стрелки ->. Значение возвращается либо оператором return, либо последним выражением тела функции (без ;):

fn plus_one(x: i32) -> i32 {
        x + 1               // неявный возврат последнего выражения
    }
    
    fn abs(x: i32) -> i32 {
        if x < 0 {
            return -x;      // явный ранний возврат
        }
        x
    }
    
    fn pair() -> (i32, i32) {
        (1, 2)              // можно возвращать кортежи
    }
    
    fn main() {
        println!("{} {} {:?}", plus_one(5), abs(-7), pair());
    }

Ключевые моменты

  • Типы параметров и返回值 обязательны в сигнатуре.
  • Блок { ... } — выражение, его значение — последнее выражение без ;.
  • return нужен только для раннего выхода, иначе возвращается последнее выражение.
