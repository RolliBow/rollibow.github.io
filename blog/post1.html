Первая запись блога

Это статическая страница в подкаталоге /blog/. Запись существует для того, чтобы у CDN появились разные пути с одинаковым набором ресурсов: и /blog/post1.html, и /about/ тянут один и тот же ../style.css — а значит, кэш Edge-сервера переиспользуется между разделами.

Что проверяем в этой записи

  • Страница в подкаталоге открывается: /blog/post1.html.
  • Стили применились (значит, ../style.css resolved верно).
  • Ссылки возврата на главную работают из любой вложенности.

Черновик заметок автора

fn main() {
        let path = "/blog/post1.html";
        println!("Запрошен путь: {}", path); // Edge отдаст из кэша при HIT
    }
