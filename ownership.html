Владение (ownership)

Владение — ключевая особенность Rust, которая обеспечивает безопасность памяти без сборщика мусора. Компилятор проверяет три правила:

  1. У каждого значения есть владелец — переменная.
  2. Владелец у значения только один.
  3. Когда владелец выходит из области видимости, значение уничтожается (вызывается drop).

Стек и куча

Типы известного размера (i32, bool, массивы) живут в стеке и копируются дешёво. String хранит данные в куче: её размер заранее неизвестен.

let s = String::from("привет"); // данные в куче
    let n = 42;                     // значение в стеке

Перемещение (move)

Присваивание данных из кучи перемещает владение — старая переменная становится недействительной. Это исключает двойное освобождение памяти:

fn main() {
        let s1 = String::from("привет");
        let s2 = s1;               // владение перемещено в s2
    
        // println!("{}", s1);     // ОШИБКА: value borrowed after move
        println!("{}", s2);        // ОК
    }

Клонирование

Если нужны две независимые копии данных в куче — используйте clone():

fn main() {
        let s1 = String::from("привет");
        let s2 = s1.clone();       // глубокое копирование данных кучи
        println!("s1 = {}, s2 = {}", s1, s2); // обе действительны
    }

Copy-типы

Типы, целиком живущие в стеке, помечены трейтом Copy: они копируются при присваивании, а не перемещаются. Это все скаляры, char, bool и кортежи/массивы из Copy-типов:

fn main() {
        let x = 5;
        let y = x;                 // копирование, а не move
        println!("x = {}, y = {}", x, y); // обе переменные действительны
    }

Владение и функции

Передача аргумента работает как присваивание: значение перемещается в функцию или возвращается из неё:

fn takes_ownership(s: String) {
        println!("{}", s);
    } // s выходит из области видимости → память освобождается
    
    fn makes_copy(n: i32) {
        println!("{}", n);
    } // n — Copy-тип, ничего не освобождается
    
    fn main() {
        let s = String::from("привет");
        takes_ownership(s);        // s перемещена
        // println!("{}", s);      // ОШИБКА: s больше не действительна
    
        let x = 10;
        makes_copy(x);             // x скопирован
        println!("{}", x);         // ОК
    }

Ключевые моменты

  • Присваивание и передача аргументов для кучевых данных — это move.
  • clone() — явное глубокое копирование, когда move не подходит.
  • Стек-типы с трейтом Copy копируются автоматически.
  • Память освобождается ровно один раз — когда владелец выходит из области видимости.
